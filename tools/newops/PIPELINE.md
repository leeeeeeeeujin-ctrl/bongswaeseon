# 신규 오퍼 그림·동작 제작 절차 (부품 방식)

언네코로 확정한 방식이다. 지피티 그림은 "컨셉과 목표 자세"이고, 게임에 들어가는 동작은 지피티가 같은 그림체로 그려 준 부품을 뼈대(rig3.js)로 움직여 만든다. 동작 하나는 끊기지 않는 하나의 클립이다.

작업 폴더는 세션 스크래치패드의 `newops/` 이다(`S/newops`). 이 폴더의 스크립트 사본이 `td/tools/newops/` 에 있다. 스크립트 안의 경로는 스크래치패드 절대 경로로 박혀 있으니, 새 세션에서는 `S/newops` 로 복사하고 경로를 바꿔 쓴다.

## 지켜야 할 것
- 올리기 전에 반드시 내 눈으로 본다: 대기 자세를 참고 그림과 같은 크기로 나란히·겹쳐서(`fit.py`), 동작은 프레임 스트립으로(`strip.py`), 게임 안에서는 확대 캡처로(`nwzoom2.js`). 관절 방향, 부착 위치, 비율, 소품 높이를 하나씩 대조한다.
- 같은 이름의 에셋 파일을 덮어쓰지 않는다. 다시 내보낼 때는 `export_list.json` 의 ver 칸을 올린다(예: "2" → "3").
- `S/one/reg.js` 결과가 `S/bak_art11/reg_before.json` 과 같아야 한다.
- 지피티 앱: 공유 링크 금지, 삭제 금지, 다 쓴 대화는 보관. 붙여넣기 뒤 입력창을 스크린샷으로 확인하고 보낸다(파일 첨부 직후에는 10초 기다린다. 안 기다리면 클립보드의 옛 글이 들어간다).

## 순서 (캐릭터 하나)
1. **참고 그림**: 대기 자세 한 장. 이미 받은 키프레임 시트의 첫 칸을 쓴다(`kf_<id>_attack.png`, `kf2_<id>_attack.png`). 없으면 `out/<id>/preview_capture.png`.
2. **목표 자세 시트**(지피티, 초록 배경 4x3): 공격 12칸, 스킬 8칸+사망 4칸. 요청문 틀은 `sheet_prompts.json`. 저장 이름 `kf2_<id>_attack.png`, `kf2_<id>_skilldie.png`.
3. **부품 시트**(지피티): 참고 시트를 붙이고 "2D 컷아웃 리그용 부품, 첫 칸과 같은 그림체·비율, 초록 배경, 부품끼리 닿지 않게, 가려진 부분까지 그리고 관절 끝은 둥글게"를 요구한다. 필요한 부품: 머리(뜬 눈), 머리(감은 눈), 몸통, 골반, 앞 위팔, 앞 아래팔+손, 뒤 위팔, 뒤 아래팔+손, 앞다리, 뒷다리, 꼬리·망토·모자 등 달린 것, 무기(손 없이). 저장 이름 `parts_<id>.png`.
4. **자르기**: 부품 시트는 연결 성분으로 자른다(`mk_unneko2.py` 앞의 자르기 코드 참고: 초록 키 → 팽창 3 → 라벨 → 행·열 순 정렬 → 이름 붙이기). 목표 자세 시트는 `python3 cutkf.py <sheet> art/<id> kfa_ 4x3`.
5. **뼈대**: `mk_unneko2.py` 를 복사해 고친다. 단위는 발이 y=0, 키 약 640. 부품마다 `s`(배율), `px,py`(부품 그림 안의 회전축), `rot`(그림 방향 보정)를 정한다. 위팔·아래팔은 따로 붙이고, 다리는 한 장을 무릎에서 휘는 메시로 쓴다. 무기는 `cross`(잡는 점 `grips`).
6. **대기 자세 맞추기**: `python3 fit.py idle 0 art/<id>/kfa_0.png <ox> <oy> out.png` → 리그 | 참고 | 겹침. 키, 다리 길이, 머리 위치, 몸통 크기, 무기 높이, 손 위치가 겹칠 때까지 고친다. `ox, oy` 는 `kfa_meta.json` 에 있다.
7. **동작**: `unneko2_u_clips.js` 의 `build(dur, impact, 표, 옵션)` 를 쓴다. 표의 한 줄이 목표 자세 한 칸이다: `[t, 골반x, 골반y, 몸통 회전, 머리 회전, 무기 Gx, Gy, 무기 각 cr, 무기 길이 csx, 앞발 x, 뒷발 x, 보간]`. `csx` 는 1이 앞, -1이 뒤, 0 근처가 화면 쪽. `impact` 는 실제 피해가 들어가는 시각이고 게임이 여기에 맞춰 재생한다. 꼬리·스카프는 몸통 회전을 조금 늦게 따라가게 자동으로 들어간다.
   - 필요한 클립: `idle`, `attack`, `skill`, `die`. 스킬이 평타를 바꾸면 `attack_<스킬id>` 를 추가한다(게임이 스킬 중에 자동으로 고른다).
8. **확인**: `python3 strip.py <dir> u_rig.json u_clips.js <전역이름> '[["attack",12],...]' out.png 0.36 300 300` 으로 목표 시트와 나란히 본다.
9. **게임에 넣기**: `art/export_list.json` 에 `[게임 id, 리그 파일, 클립 파일, 전역 이름, ver, 폴더]` 를 넣고 `python3 art/export_nw.py` → `td/nwclips.js` 와 에셋 생성. `python3 build.py`. 폴더에 `kf.json` 이 있으면 완성 그림 재생이 되니 부품 방식에서는 두지 않는다.
10. **마지막 확인과 배포**: 회귀 확인 → `node nwzoom2.js <id> 7` (공격·스킬·사망 확대 캡처) → `bash deploy_dev.sh "msg"`.
